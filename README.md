# 个人简历网站

我的个人在线简历网站。

## 预览

打开 [https://wuwuw666.github.io/my-tools](https://wuwuw666.github.io/my-tools) 查看

## 功能

- 响应式设计，支持手机、平板、电脑
- 现代化 UI 设计
- 打印友好
- 技能进度条展示
- 项目经历展示

## 本地预览

直接用浏览器打开 `index.html` 文件即可。

## 自定义

1. 修改 `index.html` 中的个人信息
2. 替换头像图片链接
3. 根据需要调整 `style.css` 样式

## 技术栈

- HTML5
- CSS3
- 响应式设计
